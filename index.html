Control de Versiones

Proyecto demostrativo de Git y GitHub

Herramientas para el desarrollo de software

Conoce los conceptos básicos del control de versiones.

Git

Sistema distribuido que permite registrar y administrar los cambios de un proyecto.

GitHub

Plataforma que permite alojar repositorios y colaborar en proyectos de software.

Commits

Registros que permiten conservar el historial de modificaciones realizadas en el código.
